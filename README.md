# Thử ngay 1.4 — Trang đầu tiên lên mạng

Trang HTML tĩnh đầu tiên của Phan Minh Nhựt, lưu trong repository public `MingNhut1309/thu-html`.

## GitHub Pages

Sau khi bật Pages tại **Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save**, trang sẽ có địa chỉ:

https://mingnhut1309.github.io/thu-html/

Mở địa chỉ trên để xác nhận trang hiển thị. Mỗi lần cập nhật mã nguồn, dùng `git add .`, `git commit -m "Mô tả thay đổi"`, rồi `git push` để cập nhật trang.
